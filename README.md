# 🏥 Clinic Database System

> Реляционная база данных для информационной системы поликлиники

## 📌 Основные возможности

- **Пациенты** — личные данные, ЭМК, полисы, аллергии
- **Расписание** — слоты приёма (врач + кабинет + время)
- **Услуги** — оказание услуг, заключения, назначения лекарств
- **Кадры** — сотрудники, должности, история ставок и зарплат
- **Склад** — лекарства, поставщики, партии, история движения

## 🛠️ Технологии

- PostgreSQL 16
- Python 3.10+ / Faker (генерация тестовых данных)
- SQL (индексы, триггеры, оконные функции, CTE, рекурсия)

## 🚀 Быстрый старт

```bash
# 1. Развернуть схему
psql -U clinic_user -d clinic -f sql/schema.sql

# 2. Сгенерировать тестовые данные
python scripts/generate_data.py

# 3. Загрузить данные
psql -U clinic_user -d clinic -f hospital_data.sql
